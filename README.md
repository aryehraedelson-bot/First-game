# FirstGame

Aryeh's first game using AI.

## ▶️ How to play

### Easiest way

1. Open the **FirstGame** folder on the computer.
2. Open a terminal in that folder.
3. Type:

```bash
npm start
```

4. Open this in the web browser:

**http://127.0.0.1:4173/**

5. Play!

### Controls

- **A / D** or **← / →** — Move
- **W / Space / ↑** — Jump
- **J** — Staff attack
- **K** — Dodge / Step
- **E** — Interact
- **L** — Lightning after it is unlocked

### Important

Keep the terminal window open while playing. When finished, close the terminal window.

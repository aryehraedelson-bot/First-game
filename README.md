# FirstGame

Aryeh's first game using AI.

## ▶️ How to play on a Chromebook with GitHub Codespaces

### Start the game

1. Open the **FirstGame** repository on GitHub.
2. Open the **Codespace/workspace** for the repository.
3. After the workspace opens, **wait 2–3 minutes** for everything to finish loading.
4. At the bottom, click **Terminal**.
5. Type:

```bash
npm start
```

6. Press **Enter**.
7. Wait for the game server to start.
8. Look for **PORTS** at the bottom of the Codespace.
9. Find port **4173** and click the **open in browser / globe** button.
10. If the Codespace shows an **Open in Browser** option for port 4173, click that.
11. The game should open in a new browser tab. Play!

### If the port is not easy to find

Go back to the Codespace/workspace and look at the bottom panel for **PORTS**. Port **4173** is the game. Use the button that opens that port in a browser.

### Controls

- **A / D** or **← / →** — Move
- **W / Space / ↑** — Jump
- **J** — Staff attack
- **K** — Dodge / Step
- **E** — Interact
- **L** — Lightning after it is unlocked

### When you are finished

1. Go back to the **Terminal** in the Codespace.
2. Press **Ctrl + C** to stop the game server.
3. You can then leave the Codespace.

### Important

Keep the terminal running while you are playing. If the game stops working, check that `npm start` is still running.
